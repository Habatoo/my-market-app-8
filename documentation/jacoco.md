## Работа с Jacoco — покрытие и отчёты

- **Покрытие считается для модулей:**
    - api
    - core
    - start

- **Для построения финального отчёта выполните команду:** <br>
```bash
./gradlew clean test jacocoTestReport
```

- **Финальный HTML-отчёт** будет доступен по пути:
  <br> [./report/build/reports/jacoco/testCodeCoverageReport/html/index.html](./report/build/reports/jacoco/testCodeCoverageReport/html/index.html)
  <>br Откройте этот файл в браузере для просмотра уровня покрытия тестами.

- **Что исключено**:  
  Покрытие НЕ считается для всех файлов, которые распологаются в папках с наименованиями `dto`, `entity`, или `mapper`.  
  Это исключение прописано в настройках Jacoco — эти классы игнорируются при расчёте покрытия.
  Кроме классов *Mapper.java в которых реализована логика маппинга данных - 
  для них реализована проверка в интеграционных тестах с поднятием контекста.
